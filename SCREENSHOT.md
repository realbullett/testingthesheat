## Color Scheme (Dark Theme)

### Main Colors:
- **Background**: `#1e1e1e` - Deep dark gray
- **Sidebar**: `#252526` - Slightly lighter dark gray
- **Accent**: `#007acc` - Bright blue (buttons, highlights)
- **Text**: `#e0e0e0` - Light gray
- **Borders**: `#3c3c3c` - Medium gray
- **Hover**: `#3e3e42` - Interactive element hover state

### UI Elements:

**New Note Button:**
- Bright blue (`#007acc`) background
- White text
- Rounded corners
- Hover effect with darker blue

**Delete Button:**
- Dark gray background
- Light gray text
- Rounded corners
- Blue border on hover

**Search Bar:**
- Dark background with subtle border
- Placeholder text in gray
- Blue border when focused
- Search icon (🔍) for visual cue

**Note List Items:**
- Transparent background by default
- Subtle hover effect
- Selected item has darker background
- Blue left border on selection
- Two-line display: title + preview

**Editor Area:**
- Large title input at top
- Timestamp info below title
- Main text area with generous padding
- Clean, distraction-free appearance

**Status Bar:**
- Character and word count
- Current status messages
- Subtle gray colors

## Key Features Visible in UI:

1. **Top Toolbar**: Quick access to New Note, Delete, and Search
2. **Left Sidebar**: List of all notes with previews
3. **Main Editor**: 
   - Large title field
   - Metadata (created/modified dates)
   - Spacious content area
4. **Status Bar**: Real-time character/word count and status updates

## Visual Polish:

- **Smooth Interactions**: Hover effects on all interactive elements
- **Clear Typography**: Readable fonts with proper sizing
- **Consistent Spacing**: Clean layouts with thoughtful padding
- **Professional Aesthetic**: Inspired by modern code editors like VS Code
- **High Contrast**: Easy to read for extended use
- **Custom Scrollbars**: Sleek, minimal scrollbar design

## Responsive Design:

- Resizable sidebar (drag the divider)
- Window can be resized
- Layout adapts to different screen sizes
- Maintains usability at various window sizes
